# APKEnabler 🚀

A lightweight and efficient utility module designed to manage, test, and enable premium features within custom mobile applications. 

`apkenabler` provides a streamlined way for developers to integrate premium state activation, handle in-app purchases or subscription states, and securely unlock features in their own mobile projects.

## ✨ Features

* **Easy Integration:** Drop-in solution to manage premium states without cluttering your core app logic.
* **Testing Ready:** Easily toggle premium features on and off during the development and testing phases.
* **Lightweight:** Minimal dependencies, ensuring your app size remains optimized.
* **Secure State Management:** Safely handle the activation logic for your premium users.
