# apkenabler 🚀

`apkenabler` is a utility Android application designed to manage, test, and activate premium features for my custom mobile applications. 

**Note:** This repository does not contain the source code. It is solely used for distributing the compiled APK files and tracking issues.

## ✨ Features

* **Premium State Management:** Easily toggle and activate premium features for integrated custom apps.
* **Testing Environment:** A quick way to test how applications behave under premium and free user states during development.
* **Simple Interface:** Lightweight, fast, and straightforward user interface to manage activation states.

## 📥 Download & Installation

You can download the latest version of the app directly from the Releases section.

1. Go to the [Releases](../../releases) page of this repository.
2. Download the latest `apkenabler.apk` file to your Android device.
3. Open the downloaded file. *(If prompted, ensure you allow installation from "Unknown Sources" in your device settings).*
4. Tap **Install** and you are ready to go!

## 🚀 How to Use

1. Launch the **apkenabler** app on your Android device.
2. Follow the on-screen instructions to select or manage the premium state for the target custom application.
3. Once activated, open your target app to see the premium features unlocked and ready for testing.
